# DCF Assumptions Advisor — 4대 실적 기반 가정 단계

## 제품 방향

기업별 DCF 가정을 검토하는 기능을 중심으로 두고, 동종기업·산업 자료는 독립 공급자로 연결한다. 사용자가 입력한 성장률·마진·자본효율 비율을 자동으로 정답 처리하지 않는다. 매출은 시간순 백테스트와 매출 유지 기준을 사용하고, 영업이익률·NWC·CapEx는 과거 분포·변동성을 검토한다. 서로 다른 검증 방법을 같은 성능 주장으로 섞지 않는다.

## 결과 계약

`revenue_agent/recommendation.py`의 `RecommendationResult`는 UI·JSON 내보내기가 공통으로 사용하는 계약이다.

| 필드 | 의미 |
|---|---|
| `verdict` | `retain`, `adjust`, `caution`, `insufficient` |
| `confidence` | `high`, `medium`, `low` |
| `user_assumption` | 단일 성장률 또는 `{연도: 성장률}` |
| `suggested_range` | 기준일까지 공개된 기업 성장률의 25%~75% 분위수 |
| `base_case` | 기업 성장률 중앙값 |
| `bear_case`, `bull_case` | 매출·마진은 25%·75%, 현금유출 비율은 75%·25% 분위수 |
| `supporting_evidence` | 사용자 가정을 지지하는 근거 |
| `conflicting_evidence` | 조정·주의가 필요한 반대 근거 |
| `data_warnings` | 비교 가능성·다년도 외삽·미연결 자료 경고 |
| `provider_status` | 기업, 최신 공시, Peer 공급자 상태 |

### Verdict 규칙

1. 공통 검증 연도가 7개 미만이면 `insufficient`다.
2. 사용자 가정 중 하나라도 권고 범위를 벗어나면 `adjust`다.
3. 범위 안이더라도 선택 방식이 최종 평가에서 매출 유지 기준을 이기지 못하면 `caution`이다.
4. 범위 안이고 선택 방식이 기준을 이기면 `retain`이다.

`retain`은 투자 의견이나 미래 실적 보장이 아니다. 현재 데이터와 운영 규칙에서 추가 조정 신호를 찾지 못했다는 의미다.

삼성전자 2025년 기준 기본 결과는 CAGR의 2023~2025년 MAPE가 15.56%, 매출 유지가 13.49%이므로 `caution`, 신뢰도 `low`다. 50%처럼 기업 과거 중앙 범위를 벗어난 가정은 `adjust`지만 최종 검증 성능이 약하므로 신뢰도는 그대로 낮다.

## 시점 통제

```text
기준 연도의 최초 검증 연간 공시일
        ↓
그날까지 공개된 연도별 최신 매출만 후보 계산에 사용
        ↓
실제 공시일이 기준일 이하인 백테스트만 방식 평가에 사용
        ↓
Verdict·Confidence·Scenario 생성
```

과거 기준 연도를 선택해도 이후 실제 실적은 방식 선택이나 신뢰도에 들어가지 않는다.

## 단일·다년도 입력

- 단일 연도: 성장률 숫자 하나
- 다년도: 기준 연도 다음부터 연속된 3~5개 연도의 성장률 딕셔너리
- 모든 성장률은 유한하며 `-100%`보다 커야 한다.
- 다년도 매출은 직전 연도 시나리오 매출에 성장률을 복리 적용한다.

현재 백테스트는 다음 회계연도 1년 예측만 검증한다. 따라서 2~5년차의 보수·기본·낙관 값은 기업 과거 성장률 분위수를 반복 적용한 참고 시나리오이며, 다년도 예측 성능이 검증됐다는 의미가 아니다. 이 제한은 `data_warnings`와 화면에 항상 표시한다.

## Peer 공급자 규격

`PeerBenchmarkProvider`는 다음 메서드를 요구한다.

```python
class PeerBenchmarkProvider(ABC):
    @property
    def status(self) -> str: ...

    def get_benchmark(
        self,
        *,
        company_name: str,
        as_of_date: pd.Timestamp,
        forecast_years: list[int],
        metric: str = 'revenue_growth',
        user_values: list[float] | None = None,
    ) -> PeerBenchmark | None: ...
```

기본 라이브 공급자는 `unconnected` 상태다. 현재 Streamlit 화면에는 공급자 연동 흐름을 검증하기 위해 `MockPeerBenchmarkProvider`를 명시적으로 주입한다. SK하이닉스·TSMC의 매출 성장률·영업이익률 샘플은 `data/peer_benchmark_mock.csv`에 있으며 모두 비검증 Mock이다. 공급자 연결 상태는 `active`지만 화면·리포트에는 Mock 경고와 출처 라벨을 항상 표시한다. 판정 자체를 뒤집지 않고 사용자 가정의 Peer 분포 백분위를 보조 지표로 제공한다.

## 영업이익률 평가

- 공식 데이터: `data/samsung_operating_margin.csv`, 2015~2025년 연간 연결 매출·영업이익 당기 값
- 영업이익률: 연결 영업이익 ÷ 연결 매출 × 100
- 권고 범위: 기준일까지 공개된 영업이익률의 25%~75% 분위수
- 보수 / 기본 / 낙관: 25% 분위수 / 중앙값 / 75% 분위수
- 변동성: 표본 표준편차가 3%p 미만이면 낮음, 3~7%p는 보통, 7%p 이상이면 높음
- 표본이 5개 미만이면 `insufficient`, 범위를 벗어나면 `adjust`, 범위 안이지만 변동성이 높으면 `caution`, 그 외는 `retain`

삼성전자 2015~2025년 기준 평균은 14.61%, 중앙값은 14.35%, 중앙 50% 범위는 12.56%~16.83%, 표준편차는 5.81%p다. 이 평가는 과거 분포 검토이며 미래 영업이익률 예측 성능을 백테스트한 것이 아니다.

## NWC·CapEx 평가

- 공식 데이터: `data/samsung_nwc_capex.csv`, 2015~2025년 연결 재무상태표·현금흐름표 당기 값
- NWC: `매출채권 + 재고자산 − 매입채무`; NWC 비율은 같은 연도 연결 매출로 나눈 값
- NWC 비율은 기말 잔액 가정이며 실제 FCFF 차감액은 연도별 잔액의 증감(ΔNWC)이다.
- CapEx: `유형자산 취득 + 무형자산 취득` 현금유출; CapEx 비율은 같은 연도 연결 매출로 나눈 값
- 권고 범위: 기준일까지 공개된 각 비율의 25%~75% 분위수
- 변동성: 표본 표준편차가 2%p 미만이면 낮음, 2~5%p는 보통, 5%p 이상이면 높음
- 현금유출 부담 방향을 반영해 보수 / 기본 / 낙관은 75% 분위수 / 중앙값 / 25% 분위수다.
- 표본이 5개 미만이면 `insufficient`, 범위를 벗어나면 `adjust`, 범위 안이지만 변동성이 높으면 `caution`, 그 외는 `retain`이다.

삼성전자 2015~2025년 NWC/매출액의 평균은 23.40%, 중앙값은 23.08%, 중앙 범위는 20.57%~26.38%다. CapEx/매출액의 평균은 16.24%, 중앙값은 17.01%, 중앙 범위는 13.09%~17.84%다. 두 평가는 미래 비율의 예측 백테스트가 아니며 사업결합·업황·투자 집행 시점의 영향을 별도로 확인해야 한다.

## 리포트·DCF 내보내기

- Markdown 리포트: 입력 가정, 판정, 신뢰도, 한 줄 해석, 찬성·충돌 근거, 경고, 공급자 상태
- JSON 리포트: 현재 세션에서 실제로 검토한 항목별 `RecommendationResult` 계약
- DCF CSV: 네 항목에 공통인 long-form 열을 사용한다. 기존 열에 `nwc_to_revenue_pct`, `capex_to_revenue_pct`, `forecast_nwc_krw`, `forecast_capex_krw`를 추가한다. 사용자가 검토한 항목만 행으로 누적하고, 검토하지 않은 지표 열은 비워 근거 없는 결합을 피한다.

## Streamlit Reviewer UX

화면은 분석 대시보드가 아니라 사용자의 DCF 가정을 검토하는 네 단계 흐름으로 구성한다.

1. **자료 확인:** 기업 자료를 선택하면 `삼성전자 2015~2025년 연결 매출 데이터를 확인했습니다.`처럼 기업·기간·재무 기준을 먼저 확정한다.
2. **질문형 입력:** 매출 성장률·영업이익률·NWC·CapEx 중 검토 항목을 선택하고 질문에 답한 뒤 `가정 검토하기`를 누른다. 3~5개년 입력은 접힌 영역에서 별도로 활성화한다.
3. **즉시 결론:** 입력 가정, 판정, 과거 기반 권고 범위, 기본 시나리오, 신뢰도와 한 줄 해석을 먼저 보여준다. 이어서 DCF에 옮길 수 있는 보수·기본·낙관 시나리오를 표시하고 공통 CSV·Markdown·JSON으로 내보낸다.
4. **판단 근거:** 입력 가정의 기업 과거 분포 및 Mock Peer 분포 백분위, 최근 실적과의 차이, 찬성·충돌 근거, 공급자 상태 및 데이터 한계를 표시한다.

네 가지 예측 방식, 세부 계산식, 연도별 오차, MAPE, 공시·비교 가능성 및 원본 다운로드는 맨 아래 `왜 이런 결론이 나왔나요? (상세 분석)` 영역에 기본적으로 접어 둔다. 사용자가 버튼을 누르기 전에는 판정이나 시나리오를 노출하지 않는다.
